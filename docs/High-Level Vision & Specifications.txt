# SK AutoSphere - High-Level Vision & Specifications

## Core Concept

SK AutoSphere is an AI-powered automotive marketplace that bridges Korean car dealers with African buyers. The platform eliminates the 30-minute listing time for sellers and provides instant, accurate vehicle information in multiple languages (Korean, English, French, Swahili) to buyers across Africa.

**Value Proposition:**
- For Korean Sellers: Transform 30-minute listing creation into <5 minutes using AI-powered description generation
- For African Buyers: Get transparent total landed costs (car price + shipping + import duties + taxes) in their local currency
- For Both: Real-time multilingual communication without language barriers

**Market Validation:**
- 8,500+ qualified African buyer leads already captured
- Validated demand in Nigeria, Kenya, Ghana, Tanzania, Rwanda
- Competitive advantage: AI-powered features + Korean market access

---

## Tech Stack Foundation

**Frontend:**
- Next.js 14 (App Router) for web application
- React Native + Expo for mobile app (iOS & Android)
- Tailwind CSS for styling
- Mobile-first responsive design (50% of sellers use mobile)

**Backend:**
- Supabase (PostgreSQL database)
- Supabase Auth for authentication
- Supabase Realtime for messaging
- Supabase Storage for images
- Row Level Security (RLS) for data protection

**AI Integration:**
- Google Gemini API for vehicle description generation
- Google Cloud Translation API for real-time message translation
- Budget: $300/month for AI features

**Deployment:**
- Web: Netlify with automatic deployments
- Mobile: Expo Application Services (EAS)

   - Shows benefits: "AI will create optimized descriptions in Korean, English, French, and Swahili in ~15 seconds"
   - Cost indicator: "Uses 1 AI credit" (if credit system)

     - "Analyzing vehicle condition..." ✓
     - "Highlighting key features..." (in progress)
     - "Optimizing for buyers..." (pending)
     - "Translating to 4 languages..." (pending)
   - Progress bar
   - Cannot navigate away (confirms if try)

3. **Success:**
   - Checkmark animation
   - "Descriptions generated successfully!"
   - Shows 4 tabbed descriptions:
     - Tab 1: 한국어 (Korean) - Active by default
     - Tab 2: English
     - Tab 3: Français (French)
     - Tab 4: Swahili

**Generated Description Display:**
Each tab shows:
- Full description (200-300 words)
- Formatting: paragraphs, bullet points for features
- Tone: Professional, factual, highlight positives
- Structure:
  - Overview (Make, Model, Year, brief condition)
  - Key Features (bullet points)
  - Condition Details (honest assessment)
  - Technical Specifications
  - Call to Action

**Edit Options:**
- Each description is fully editable
- Character counter (min 100, max 1000 per language)
- "Regenerate" button (uses another AI credit)
- "Translate from Korean" button (for manual translations)

**Preview:**
- Button: "Preview Listing" (opens modal showing how it looks to buyers)

**Buttons:**
- "Save Draft"
- "Back" (returns to vehicle details)

- "Continue to Pricing" (validates min length)

**Error Handling:**
- If AI fails: "AI service unavailable. You can:"
  - Retry (button)
  - Switch to manual entry (button)
  - Save draft and come back later
- If API quota exceeded: "Daily AI limit reached. Try tomorrow or enter manually."

**Cost Optimization:**
- Cache descriptions for 7 days (reuse if seller edits same listing)
- Only regenerate languages that changed
- Track API usage per seller (prevent abuse)

**User Flow:**
1. Seller arrives with vehicle details saved

3. Optionally adds highlights

5. Waits 15 seconds watching progress
6. Reviews generated descriptions in all languages
7. Makes any edits needed

## AI Integration Details

### AI Description Generator (Google Gemini)

**Input:**
- 6-20 vehicle photos
- Vehicle details (make, model, year, mileage, condition)
- Optional seller notes

**Process:**
1. Upload photos to Supabase Storage
2. Send photo URLs + context to Gemini API
3. Gemini analyzes:
   - Vehicle condition from photos
   - Visible features
   - Any damage or issues
   - Overall appeal
4. Generates description optimized for:
   - SEO keywords
   - Buyer appeal
   - Honest condition assessment
   - Call to action
5. Generates in Korean first (250-300 words)
6. Translates to English, French, Swahili

**Output:**
- 4 descriptions (one per language)
- Structured format (overview + features + condition)
- Formatted with paragraphs and bullets

**Cost Optimization:**
- Cache descriptions for 7 days
- Track API usage per seller
- Set monthly budget: $300
- Degrade gracefully if budget exceeded

**Error Handling:**
- Timeout after 30 seconds
- Fallback to manual entry
- Retry logic (up to 3 attempts)
- Show error message if failed

---

### Real-Time Translation (Google Cloud Translation API)

**Input:**
- User message text
- Source language (detected or specified)
- Target language (recipient's preference)

**Process:**
1. User types message in their language
2. Message saved to Supabase in original
3. On send, detect source language
4. Translate to recipient's language
5. Show both original and translated
6. Store both versions

**Output:**
- Translated message
- Original message (accessible via toggle)
- Language indicators

**Cost Optimization:**
- Batch translations when possible
- Cache common phrases
- Only translate when languages differ
- Budget: $100/month

  - Warning message before publish
